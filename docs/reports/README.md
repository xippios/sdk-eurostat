# Reports

This folder holds the dated reports of this repository: the evidence a decision or a change
rests on, such as a probe of the upstream or a measurement, written once and cited by its
URL. This README stays.

- **Its name.** `docs/reports/YYYY-MM-DD-<slug>.md`, the day it was written. `<slug>` names
  its subject in lowercase letters and digits, its words joined by hyphens.
- **Its form.** The first line reads `# <subject>, YYYY-MM-DD`. What was found comes first,
  then `## Basis`, what it was found from, each command, source and commit by its link, then
  a section per finding.
- **Once.** A report stands as it was merged. A later finding is a report of its own, which
  cites the earlier one.
