Source of truth for every endpoint wrapper (sdk-core ADR-0028). The files in this
directory are written by `scripts/refresh_upstream.py` (`/refresh-upstream`) from the
pages in the table below and refreshed deliberately by PR, so that changes show up as
diffs. This file is generated by the same script; nothing here is edited by hand but
`OBSERVED.md`, where it exists: what upstream does but never documents, each note with
its evidence.

## How this is captured

The user guide "Data access via API"
(https://ec.europa.eu/eurostat/web/user-guides/data-browser/api-data-access/) is a set
of server-rendered pages. Each page under `user-guide/` is converted to Markdown with
the standard library's `html.parser`: the page's `h1` becomes the title and the page's
main region (`id="main-content"`) the body, including the code snippets and notes the
site places beside the articles; links and images are made absolute, and a table with
merged cells or a nested table is kept as simplified HTML. The site's navigation,
header, footer, scripts and styles are dropped. The pages' HTML carries a per-request
token, which the Markdown drops, so a page's row records no size or sha256, and its
file's diff shows a change.

The user-guide pages are the website's editorial content, reproduced here as this
package's reference with the source acknowledged in each row below; Eurostat's copyright
notice asks that a modification be stated and that a disclaimer of Eurostat's
responsibility be included. Changes made: each page is converted from HTML to Markdown,
as the paragraph above says; the WADL files, the OpenAPI document and the samples are
kept verbatim. The Markdown pages under `user-guide/` are this package's conversion of
Eurostat's pages; Eurostat is not responsible for this reproduction or for any
difference from the pages it serves. The copyright notice is read for the statements
under Attribution, which it must print on every run, and is kept as no file.

The WADL files and the OpenAPI document come from
https://ec.europa.eu/eurostat/api/dissemination/, those under `api/comext/` from
https://ec.europa.eu/eurostat/api/comext/dissemination/, the second base, which serves
the `DS-` datasets of Comext and Prodcom. The service generates its WADL files per
request and orders sibling elements (`resource`, `method`) differently from one request
to the next. A WADL answer whose lines, each taken with the lines that enclose it by
indentation, are exactly those of the file already here leaves the file as it is, so a
diff shows changes only, a line moved under another parent included; the namespace
prefixes a line declares for itself (`ns3`, `ns4`, numbered by the service in document
order) are masked for that comparison, and `--check` compares a WADL file in that form.
The OpenAPI document is compared byte for byte.

The samples are answers for one dataset of each base (`apro_mk_cola`, `DS-059358`), one
country and two periods, each the Statistics API's JSON-stat and the SDMX 2.1 API's
SDMX-CSV; the script checks for each that the SDMX-CSV's dimension columns follow the
order of the JSON-stat `id`, that the key has one position per dimension, that every
SDMX-CSV row lies inside the key, and that the data-query page states the key's order.
JSON-stat 2.0 is a third-party specification (https://json-stat.org/format/): cited, not
snapshotted.

Eurostat's wiki holds two Confluence pages on the API:
https://wikis.ec.europa.eu/x/-AD9B, on SDMX 2.1 and asynchronous answers, and
https://wikis.ec.europa.eu/x/c4eBBg, on the TSV format. Both require EU Login, so the
snapshot requests neither, and the public pages of the user guide are its statement of
their subjects.

After a 429 the one retry waits as long as the website asks in
`X-Rate-Limit-Retry-After-Seconds` or `Retry-After`, 60 s where it names no wait, and a
wait over 900 s stops the run.

Fetched is the UTC time the run started, in ISO 8601 with an explicit Z, the same for
every row. Bytes and sha256 are those of the body as fetched: a converted page's row
holds the HTML page's, an excerpt's the whole document's, a file split from a page the
page's. Last-Modified is the HTTP header in UTC, or as sent in a code span where it is
no HTTP date, and ETag is as sent, in a code span, on a row that ends in a comment
telling the secret scan it is no key. A page recorded without a file is `(no file)`, and
a body that changes on every request records no size, sha256 or ETag. A sample is a
small answer of the API kept verbatim under `samples/`, which documents the answer's
shape and is no test fixture. Requests go one at a time, 5 s apart, through core's
client, each retried at most once and no sooner than 10 s, a 429 after the wait the
client gives it where that is longer, and are identified as `xippios-eurostat/<version>
(+https://github.com/xippios)`, the source package's version in place of `<version>`. No
redirect to another host is followed and no browser is imitated. No key is sent or read.
A page an anonymous client cannot read is requested once and listed under Not fetched.
