## About Statistical Data and Metadata Exchange (SDMX)

The Statistical Data and Metadata Exchange ([SDMX](https://sdmx.org/)) initiative is sponsored by a wide range of public institutions, including [Eurostat](http://ec.europa.eu/eurostat/). This standard describes and universalizes the way to exchange statistical data, and provides standard formats for data and metadata, content guidelines as well as IT architecture for exchange of data and metadata.
